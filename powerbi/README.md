# Power BI Dashboard

Interactive Power BI dashboard developed to analyze the global evolution of COVID-19, vaccination progress, and health outcomes across 218 countries and territories.

## Dashboard Pages

### 1. Global Overview
Global pandemic indicators, including confirmed cases, deaths, vaccination progress, and historical trends.

### 2. COVID-19: Income & Health Outcomes
Comparative analysis of pandemic outcomes across countries grouped by income classification.

### 3. Methodology & Data
Overview of the analytical methodology, data sources, model structure, and key considerations.

## Technical Implementation

- **Power BI:** Dashboard development and data visualization.
- **DAX:** Measures and analytical calculations.
- **Data Model:** Dimensional model with fact and dimension tables.
- **Data Source:** Google BigQuery.
